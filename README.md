## About

I'm a Computer Engineering graduate (July 2026, CGPA 8.47) from Pune, India, building at the intersection of **AI Engineering** and **software systems**.

My work spans **federated learning security**, **generative AI developer tooling**, and **agentic, multi-agent systems**. I like turning research-shaped ideas into systems that actually run: RAG pipelines, async backends, and agents that make decisions with real confidence scoring.

One of my projects, **FedShield**, was presented at **IEEE ICCUBEA 2026**, and I contributed to **SATHI**, an AI-driven mental wellness system deployed for CRPF personnel that received official technical acceptance from the Government of India.

<details>
<summary><b>🧠 DevMind</b> — Context-Aware Debugger & Code Memory <i>(Jan 2026 – Mar 2026)</i></summary>
<br>

A VS Code extension that gives LLMs structural code context instead of raw text, plus a self-learning memory of past fixes.

| | |
|:---|:---|
| **Focus** | Generative AI / Developer Tooling |
| **Approach** | Python AST parser extracts structural code context, cutting boilerplate & reducing LLM token consumption by 90%+ |
| **Retrieval** | Self-learning RAG pipeline (LangChain + ChromaDB) indexing resolved errors & snippets for personalized fix suggestions |
| **Performance** | Async FastAPI backend with Redis semantic caching, delivering real-time debugging in <300ms |
| **Stack** | Python • FastAPI • React.js • LangChain • ChromaDB • Groq API (Llama-3) • Redis |

</details>

<details>
<summary><b>🛡️ FedShield</b> — Robust Federated Learning Defense System <i>(Final Year Project)</i></summary>
<br>

A hybrid defense framework securing Federated Learning against backdoor and data-poisoning attacks.

| | |
|:---|:---|
| **Focus** | Federated Learning Security / Adversarial ML |
| **Approach** | Hybrid defense (Behavioral Shift Guard + Last-Layer Gradient Anomaly) with secure aggregation to block BadNets & label-flipping attacks |
| **Results** | Explainable trust-scoring system achieving **>90% reduction in Attack Success Rate (ASR)** vs. FedAvg, with global model performance preserved |
| **Visualization** | Interactive Streamlit dashboard for real-time client-wise anomaly scores & rejection decisions |
| **Stack** | Python • PyTorch • Streamlit • Federated Learning (FedAvg) |
| **Status** | Presented and submitted at IEEE ICCUBEA 2026; publication pending |

</details>
